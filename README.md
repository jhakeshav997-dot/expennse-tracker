# Expense Tracker

Simple desktop application built with Python (Tkinter) and SQLite to track daily expenses.

## Features
- Add, view, and delete expenses
- Date picker for easy date selection
- Category dropdown (Food, Travel, Gym, Bills, etc.)
- Monthly category-wise pie chart
- Export all data to CSV

## Tech Stack
- Python 3
- Tkinter (GUI)
- SQLite (Database)
- Matplotlib (Charts)
- tkcalendar (Date picker)

## How to Run
1. Install dependencies: pip install tkcalendar matplotlib
2. Run the file: python expense-tracker.py
